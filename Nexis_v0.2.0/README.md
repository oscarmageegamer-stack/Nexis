# Nexis v0.2.0

Modular command-line framework for authorised ethical security testing.

## Install on Windows
From this folder in PowerShell:
`py -m pip install -e .`
Then open a new terminal and run `nexis`.

## Install on Kali/Linux
`python3 -m pip install -e .`
Then run `nexis`.

## New in v0.2.0
- Local network discovery
- Automatic local IPv4/subnet detection
- Nmap host discovery integration
- IP, MAC and hostname information where available
- Latency measurements
- Wi-Fi adapter information
- JSON discovery reports
- Existing recon, crypto, web and host modules

Only test systems, networks and devices you own or have explicit permission to assess.
